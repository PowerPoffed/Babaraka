Привет. Я Евгений, делаю YouTube-ролики (отвечай по-русски, коротко и пошагово).
Нужно сделать программу, которая сама подбирает и скачивает БЕСПЛАТНЫЕ легальные видео-футажи
со стоковых сайтов под мой список кадров. Работаем в этой папке на моём компьютере (Windows).

ЧТО У МЕНЯ ЕСТЬ
- Node.js (на нём моя программа «YouTube Image Studio» и скрипты рендера). Python ставить не нужно.
- Список кадров ролика: файл shots.txt, строки вида  текст фразы|место|тип|описание сцены
  (или prompts.txt / animate.txt вида  shot_001|описание). Покажу пример, если нужно.
- Картинки делаю в Google Flow, озвучку в ElevenLabs, монтаж в CapCut.

ЧТО НУЖНО СДЕЛАТЬ
1. Скрипт stock_footage.js (Node 18+, встроенный fetch, без лишних библиотек) + файл запуска
   СКАЧАТЬ_ФУТАЖИ.bat (перетащил список кадров на .bat → всё скачалось). Окна и сообщения — по-русски.
2. Источники (только легальные, разрешено использовать в монетизированных роликах):
   - Pexels Video API (бесплатный ключ: pexels.com/api)
   - Pixabay Video API (бесплатный ключ: pixabay.com/api/docs)
   - по желанию: Wikimedia Commons (исторические видео/фото, у многих нужна подпись автора — CC BY),
     Internet Archive / Prelinger (старая кинохроника, общественное достояние), NASA (космос).
   НИКОГДА не брать видео с YouTube, TikTok, Instagram и кадры из фильмов/ТВ.
3. Ключи хранить в config.json рядом со скриптом (создавать из config.example.json при первом запуске
   и открывать Блокнотом). config.json добавить в .gitignore, ключи никуда не отправлять и не печатать.
4. Поисковые слова: ТЫ (Claude) по моему списку кадров составляешь файл search_terms.txt —
   для каждого кадра 2–3 короткие английские фразы для стоков (например
   shot_012|aerial volcano island|smoking volcano sunrise|fishing boats harbor).
   Скрипт ищет по ним по очереди.
5. Выбор клипа:
   - горизонтальный, минимум 1280 px по ширине (лучше 1920), длина не меньше нужной (по умолчанию 5 сек;
     если есть shot_times.json из моей программы — брать длительность оттуда);
   - один и тот же клип не повторять в разных кадрах;
   - качать подходящий файл (HD, не 4K, чтобы не тратить место) в папку footage/ как shot_001.mp4 и т.д.;
   - уже скачанные кадры пропускать (можно перезапускать).
6. Файл источники.txt: для каждого кадра — сайт, ссылка на страницу клипа, автор, лицензия.
   Отдельно список для описания ролика (где нужна подпись автора).
7. Файл не_найдено.txt: кадры без подходящего видео — их сделаю картинкой во Flow.
   Для них сразу допиши промт для Flow в моём стиле.
8. Соблюдать лимиты API (проверь в документации Pexels и Pixabay, делай паузы между запросами),
   при ошибке сети — повтор до 3 раз.
9. ИНСТРУКЦИЯ.txt простыми словами: как получить ключи, куда вставить, как запускать.

ВАЖНО ДЛЯ YOUTUBE
Ролик только из стоковых видео + синтетический голос YouTube может посчитать «повторно используемым
контентом» и отключить монетизацию. Поэтому футажи — только часть кадров: смешиваем со своими
AI-картинками, картами и моушном. Предложи, какую долю кадров лучше закрывать футажами.

ПОРЯДОК
Сначала коротко покажи план и структуру файлов, потом пиши код. После — проверим на 10 кадрах.

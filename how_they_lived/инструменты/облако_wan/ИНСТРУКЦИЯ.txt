ОЖИВЛЕНИЕ КАДРОВ НА АРЕНДОВАННОЙ ВИДЕОКАРТЕ
Модель: Wan 2.2 14B (картинка -> видео) + Lightning LoRA, 4 шага. Бесплатная, открытая.
Платите только за аренду видеокарты: примерно $0.4-0.9 в час.

=== ОДИН РАЗ: ПОДГОТОВКА ===

1. Зарегистрируйтесь на runpod.io и пополните баланс ($10-20).
2. Storage -> Network Volume -> Create: 60 ГБ, регион, где есть RTX 4090/5090.
   Стоит около $4 в месяц. Модели скачаются на него один раз.
3. Settings -> API Keys -> Create API Key (права: All или Read/Write).
   Скопируйте ключ. НИКОМУ ЕГО НЕ ОТПРАВЛЯЙТЕ, в GitHub не кладите.
4. В этой папке запустите ОЖИВИТЬ_В_ОБЛАКЕ.bat один раз: он создаст config.json и откроет его.
   Вставьте ключ в "runpod_api_key" и сохраните.
   Скрипт выключит видеокарту, когда всё закончит. Без ключа выключайте вручную!

=== КАЖДЫЙ РАЗ: ЗАПУСК ===

1. runpod.io -> Pods -> Deploy:
   - видеокарта: RTX 5090 или RTX 4090
   - Network Volume: ваш
   - Template: ComfyUI (официальный или самый популярный)
   - Deploy. Подождите 3-5 минут.
2. Только в ПЕРВЫЙ раз: скачайте модели (около 10 минут).
   Connect -> JupyterLab -> перетащите в него файл setup_pod.sh
   -> File -> New -> Terminal -> введите:  bash setup_pod.sh
   Дождитесь надписи ГОТОВО.
3. Connect -> скопируйте адрес порта 8188. Он выглядит так:
   https://abc123xyz-8188.proxy.runpod.net
   Вставьте его в config.json в "servers" (вместо старого адреса).
   ДВЕ видеокарты = вдвое быстрее: запустите второй под и добавьте второй адрес через запятую:
   "servers": ["https://aaa-8188.proxy.runpod.net", "https://bbb-8188.proxy.runpod.net"]
   Второй карте тоже нужен setup_pod.sh, если у неё другой Network Volume.
4. Запустите ОЖИВИТЬ_В_ОБЛАКЕ.bat:
   - перетащите файл списка (animate.txt) и нажмите Enter
   - перетащите папку с картинками и нажмите Enter
5. Клипы появятся в папке video_clips рядом с папкой картинок: shot_001.mp4, shot_002.mp4...
   Когда всё готово, скрипт сам выключит видеокарту (Stop).
   Если хотите удалить её совсем, нажмите Terminate на сайте. Network Volume с моделями останется.

=== СПИСОК КАДРОВ ===

Каждая строка: номер кадра | промт движения
  shot_001|The canoe glides slowly, the water ripples. Keep exactly the same cartoon style...
Длительность (по умолчанию 4 сек, меняется в config.json -> "default_seconds"):
  shot_001|3|промт                  -> 3 секунды
  shot_001|промт ... 5 sec          -> 5 секунд (можно "3s", "4 sec", "5 seconds", "4 сек", "[3s]")
  Больше 5 секунд нельзя: Wan начинает портить картинку.
[HD] в промте -> этот кадр будет 1280x720 (дольше примерно в 2,5 раза). Остальные 832x480.
Картинка ищется по номеру: shot_001.png / shot_001.jpg / shot_001_v2.png

=== ЕСЛИ ЧТО-ТО НЕ ТАК ===

- Клип получился плохой: удалите его mp4 и запустите снова. Скрипт сделает только недостающие.
- Скрипт прервался или отключился интернет: просто запустите снова.
- "не отвечает": под ещё запускается или выключен. Подождите или запустите на сайте.
- "нет моделей": не сделан шаг 2 (setup_pod.sh) на этой видеокарте.
- Любая другая ошибка: пришлите Claude скриншот окна. Ключ API на скриншоте не показывайте.

=== СКОЛЬКО СТОИТ (примерно, проверьте на первом запуске) ===

Один клип 4 сек 832x480 на RTX 4090: около 40-60 секунд.
500 клипов: 6-8 часов на одной карте или 3-4 часа на двух. Это $3-6 в день.
Время на каждый клип и сколько осталось скрипт показывает сам.

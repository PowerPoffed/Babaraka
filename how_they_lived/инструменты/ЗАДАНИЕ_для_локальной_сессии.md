## Что нужно сделать в программе

### 0. САМОЕ ВАЖНОЕ — загрузка готовых картинок из Google Flow в проект
Картинки теперь делаются в Google Flow (Nano Banana), а не в ComfyUI. Программа должна уметь взять их и собрать видео.
- На странице проекта кнопка «Загрузить картинки (Flow)»: выбрать папку с картинками.
- Номер кадра брать из имени файла: `shot_012.png`, `shot_12.jpg`, `12.png`, `image_012.png` — первое число в имени.
  Файлы без номера — показать списком «не распознаны», их можно перетащить на нужный кадр вручную.
- Картинку привести к 1920×1080: если меньше — апскейл (RealESRGAN_x4plus_anime_6B через ComfyUI, если запущен; иначе ffmpeg lanczos),
  если другая пропорция — обрезка по центру до 16:9. Положить в `final/` как выбранный вариант этого кадра.
- Если у кадра уже есть картинка — заменить (старую сохранить в `final/_old/`).
- Показать отчёт: сколько кадров загружено, каких номеров не хватает (например «нет: 34, 35, 102»).
- Перетаскивание одной картинки на кадр в пикере = заменить этот кадр (для переделок).

### 2. Кнопка «Видео» ВНУТРИ ПРОЕКТА — анимация ключевых кадров через Wan 2.2 5B
Кнопка должна быть на странице открытого проекта (там, где выбор лучших кадров,
«Сохранить лучшие в final» и блок таймингов SRT) — она работает с картинками этого проекта.
Отдельный блок «Видео (анимация кадров)»: выбор файла со списком, кнопка «Анимировать», прогресс, список готовых клипов с превью.
- Читает файл `animate.txt` или `animate_first_minute.txt` из папки проекта
  (строки `shot_002|промпт движения`). Выбор файла — в интерфейсе.
- Для каждой строки берёт ВЫБРАННУЮ картинку кадра из `final/`,
  загружает её в ComfyUI (`/upload/image`) и отправляет workflow (см. ниже).
- Сохраняет клип в `video_clips/shot_XXX.mp4`. Уже готовые клипы пропускает.
- Показывает прогресс (кадр N из M, время на клип). Очередь последовательная.
- Рабочий workflow уже проверен — он есть в `animate_wan.ps1` (в архиве ролика). Перенести его в код.

**Проверенные настройки Wan (быстрый режим):**

### 7. Моушн-графика (титры, карты, цифры) — кнопка «Моушн» в проекте
Готовый движок лежит в папке `моушн/` (anim.html + render.js + world_land.js, нужен Node.js и ffmpeg). Его НЕ переписывать — вызывать.
- В проект можно загрузить `motion_plan.json` (рядом с prompts.txt его даёт Claude для каждого ролика).
- Кнопка «Моушн»: программа уже знает время начала каждого кадра (из SRT). Записать его в папку проекта
  `shot_times.json` вида `{"shot_001": 0.0, "shot_002": 3.1, ...}` (секунды), положить туда же `motion_plan.json`
  и запустить `node <путь>/моушн/render.js <проект>/motion_plan.json`.
  render.js сам: рендерит элементы (с кэшем — повторно только изменённые), укорачивает наезжающие и собирает
  `моушн/out/<папка проекта>/ALL_overlays.mov` (прозрачное видео на весь ролик) + `timings.txt`.
- Показывать прогресс из вывода render.js (строки `[N/M] готово: ...`).
- При «Собрать видео» — галочка «Добавить моушн-графику»: наложить ALL_overlays.mov поверх ролика с 0:00
  (ffmpeg `overlay=format=auto:eof_action=pass`). Если файла нет — собрать без него.
- Первый запуск: если в папке моушн нет node_modules — выполнить `npm install` там (ставит playwright, браузер — встроенный Edge).

МОУШН-ДИЗАЙН ПО ПЛАНУ (бесплатно, на своём ПК)

ОДИН РАЗ:
1. Установить Node.js (LTS) с https://nodejs.org — «Далее, Далее, Готово».
2. Проверить ffmpeg: в PowerShell  ffmpeg -version  должно что-то вывести.

КАЖДЫЙ РОЛИК:
1. В папке ролика (например ролик_сон) должны лежать:
   - motion_plan.json — какие титры/карты/плашки на каких кадрах (его делает Claude вместе с промптами);
   - shotpos.json     — где в тексте начинается каждый кадр (уже есть);
   - субтитры .srt    — экспорт субтитров из CapCut по готовой озвучке (любое имя, например subs.srt).
2. Перетащить motion_plan.json мышкой на СДЕЛАТЬ_ТИТРЫ.bat
   (или просто дважды щёлкнуть — тогда возьмёт ..\ролик_сон\motion_plan.json).
3. Результат в папке out\<папка ролика>:
   - ALL_overlays.mov — ОДНА прозрачная дорожка на весь ролик. В CapCut положить её поверх видео с 0:00 — всё встанет само.
   - shot_008_map.mov, shot_043_name.mov ... — те же элементы по отдельности (если хочется поправить вручную);
   - timings.txt — во сколько начинается каждый элемент.
   Если .srt нет — будут только отдельные файлы по номерам кадров.
4. Перезапуск: уже готовые элементы не рендерятся заново. Чтобы переделать один — удалить его файл в out.

ТИПЫ ЭЛЕМЕНТОВ в motion_plan.json:
  title  — большая дата по центру:         {"shot":"shot_001","type":"title","text":"200,000 YEARS AGO","sub":"SOUTHERN AFRICA"}
  map    — карта с булавкой (любое место):  {"shot":"shot_008","type":"map","label":"BORDER CAVE","sub":"SOUTH AFRICA","lon":31.99,"lat":-27.02,"view":"africa"}
           lon/lat — долгота/широта места (из Google Maps: правый клик → первые цифры это широта, вторые долгота;
           в плане порядок наоборот: lon = второе число, lat = первое).
           view — с какого вида начинается карта: africa, europe, mediterranean, middleeast, asia, americas, world;
           без view — регион вокруг места. zoom — насколько приближать к булавке (обычно 2.6, для маленьких островов 4).
  source — плашка «SOURCE» слева сверху:   {"shot":"shot_009","type":"source","text":"Wadley et al., <i>Science</i>, 2020"}
  name   — имя учёного / народ / место:     {"shot":"shot_043","type":"name","text":"Richard Wrangham","sub":"ANTHROPOLOGIST"}
  number — большая цифра справа сверху:    {"shot":"shot_090","type":"number","value":15,"sub":"BEDDING LAYERS"}  (value — считает от 0)
                                           {"shot":"shot_156","type":"number","text":"10–30%","sub":"OF ADULTS"}      (text — без счёта)
  compare — столбики (справа сверху):     {"shot":"shot_227","type":"compare","title":"HOURS OF SLEEP","items":[{"label":"HUMANS","value":7,"text":"7 H"},{"label":"CHIMPANZEES","value":9.5,"text":"9.5 H"}],"step":2.4}
  timeline — линия времени (сверху):      {"shot":"shot_071","type":"timeline","points":[{"t":"200,000","sub":"BORDER CAVE"},{"t":"77,000","sub":"SIBUDU"}],"active":1}
  myth    — МИФ зачёркивается → ФАКТ:     {"shot":"shot_136","type":"myth","myth":"10–12 HOURS","fact":"6–7 HOURS"}
  quote   — крупная фраза по центру:       {"shot":"shot_015","type":"quote","text":"WHO KEPT WATCH?","sub":"(не обязательно)"}
  checklist — список с галочками (слева): {"shot":"shot_034","type":"checklist","title":"OUR EARLY ANCESTORS","items":["SMALL","LIGHT","-BAD AT X"],"step":0.7}
             "-" перед пунктом = красный крестик; "mark":"x" = крестики у всех; step — секунд между пунктами.
  alert   — опасность (справа сверху):      {"shot":"shot_097","type":"alert","sub":"ENEMY #1","text":"COLD"}
  label   — подпись со стрелкой:            {"shot":"shot_003","type":"label","text":"GRASS BUNDLES","x":0.5,"y":0.55}
             x, y — куда показывает стрелка (доля кадра: 0 — лево/верх, 1 — право/низ). Если стрелка мимо — поправьте x, y.
  "dur": 3.5 — длительность в секундах (не обязательно). Если два элемента в одном месте экрана
  наезжают друг на друга, скрипт сам укоротит первый. Если поменять текст в плане — перерисуется только этот элемент.
  Карта — настоящая карта мира (Natural Earth, свободная лицензия): Шотландия, Египет, Рим, Скандинавия — всё работает.

ЧТО НАПИСАТЬ CLAUDE ДЛЯ НОВОГО РОЛИКА:
  «Сделай motion_plan.json по тексту и кадрам: даты — title, места — map, учёные и народы — name,
   исследования — source, яркие цифры — number. Как можно больше: примерно элемент на каждые 2–3 кадра, все 12 видов.»

Время: ~30 сек на элемент; ролик про сон (95 элементов) ≈ 45–60 мин — можно запустить и уйти. ALL_overlays.mov ~0,7–1 ГБ.
Посмотреть анимацию без рендера: открыть anim.html в браузере (крутится карта).

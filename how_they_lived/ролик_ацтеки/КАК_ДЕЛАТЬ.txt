РОЛИК ПРО АЦТЕКОВ — ЧТО ДЕЛАТЬ ПО ШАГАМ

0. ПРОГРАММА (один раз, локальная сессия Claude на ПК)
   Открыть Claude Code → Local → папка «СОЗДАТЬ РОЛИК», дать ему файл
   инструменты/ЗАДАНИЕ_для_локальной_сессии.md. Главное: пункт 0 (загрузка картинок из Flow) и пункт 7 (моушн).
   Пока программу не доделали — можно делать картинки и озвучку, это от программы не зависит.

1. КАРТИНКИ во Flow (0 кредитов)
   а) Инструкции агента — flow_INSTRUCTIONS.txt (старые про сон выключить).
   б) Референсы персонажей — flow_REFERENCES.txt → выбрать лучшие → прикрепить к инструкциям.
   в) Пачки по 24 — flow_batches_of_24.txt (10 пачек, 232 кадра). Каждую пачку отдельным сообщением.
      ПАЧКА 1 = первая минута (кадры 1–24) — все её кадры уже подготовлены под анимацию.
      Ещё 34 ключевых кадра дальше по ролику тоже подготовлены (в промпте «Animation-ready composition»).
   г) Скачать, назвать shot_001.png … shot_232.png, сложить в одну папку.
   Ошибка фильтра Google — прислать Claude номер кадра.

2. ОЗВУЧКА
   voiceover_EN.txt — 1600 слов, ~8 960 символов (≈ 9 000 кредитов ElevenLabs), ~9,9 мин при вашем темпе.
   Можно по частям: ОЗВУЧКА_по_частям.txt (11 частей).
   Потом в CapCut — английские субтитры → экспорт .srt.

3. СБОРКА в программе
   prompts.txt → новый проект (название возьмётся из первой строки) → загрузить картинки из Flow
   → voiceover_EN.txt + Picker/.shotpos.json + .srt (тайминги) → MP3 → собрать видео.

4. АНИМАЦИЯ — подробно в АНИМАЦИЯ.txt
   57 кадров: вся первая минута (23) + 34 ключевых. Промпты движения написаны вручную под каждый кадр.
   animate_first_minute.txt и animate_key_shots.txt → Wan на ПК (animate_wan.ps1 или кнопка «Видео»).
   10 «герой-кадров» с движением персонажей → Flow (Veo 3.1 Lite / Omni Flash), ~100 кредитов = 2 дня бесплатных.

5. МОУШН-ГРАФИКА
   motion_plan.json — 109 элементов, примерно каждые 5–6 секунд: карта, цены в какао-бобах столбиками,
   линия времени 1325–1521, списки «рецепт тортильи», «как построить чинампу», подписи со стрелками, цифры, миф/факт…
   Пример первой минуты — моушн_первая_минута_ацтеки.mp4.
   Положить .srt в эту папку → перетащить motion_plan.json на моушн/СДЕЛАТЬ_ТИТРЫ.bat
   → моушн/out/ролик_ацтеки/ALL_overlays.mov → в CapCut поверх видео с 0:00.
   (После доработки программы — кнопка «Моушн» сделает это сама.)

6. ПУБЛИКАЦИЯ
   packaging.txt — название (рекомендую №1), идея обложки + промпт, теги.
   description.txt — готовое описание: главы, факты из ролика и 30 ссылок на Википедию + первоисточники.

ФАЙЛЫ: research.txt — факты и источники; storyboard.txt — раскадровка с временем; shots.txt + build_aztec.py — исходник
(если надо поменять текст или кадр — правится shots.txt и запускается python build_aztec.py).

КАК ЗАПУСТИТЬ ВСЁ НА СВОЁМ ПК — по шагам

========================================
ШАГ 1. РАСПАКОВАТЬ АРХИВ (2 мин)
========================================
1. Скачать архив How_They_Lived.zip.
2. Правый клик → «Извлечь всё…» → указать папку:
      C:\Users\hapuk\Desktop\СОЗДАТЬ РОЛИК\How_They_Lived
   (именно внутрь папки программы — так локальная сессия Claude увидит и программу, и все файлы ролика).
3. Внутри должны быть папки: ролик_ацтеки, ролик_сон, моушн, инструменты, flow_agent, темы.

========================================
ШАГ 2. ПОСТАВИТЬ NODE.JS И ПРОВЕРИТЬ FFMPEG (5 мин, один раз)
========================================
1. Зайти на https://nodejs.org → скачать «LTS» → установить (Далее, Далее, Готово).
2. Открыть PowerShell (Пуск → набрать PowerShell) и ввести по очереди:
      node -v
      ffmpeg -version
   Обе команды должны вывести версию.
   Если ffmpeg «не найден» — ничего страшного: в шаге 3 скажите Claude «поставь ffmpeg», он сделает.

========================================
ШАГ 3. ЛОКАЛЬНАЯ СЕССИЯ CLAUDE — ДОРАБОТКА ПРОГРАММЫ
========================================
1. Открыть приложение Claude → вкладка Code → вверху выбрать «Local» (на этом компьютере).
2. Выбрать папку: C:\Users\hapuk\Desktop\СОЗДАТЬ РОЛИК
3. Отправить первым сообщением (скопировать целиком):

----- начало сообщения -----
Прочитай файл How_They_Lived\инструменты\ЗАДАНИЕ_для_локальной_сессии.md и выполни его по порядку:
сначала пункт 0 (загрузка картинок из Google Flow в проект), потом пункт 7 (кнопка «Моушн»,
движок лежит в How_They_Lived\моушн), потом остальные. После каждого пункта — короткая проверка
и отчёт мне по-русски в 2–3 строки. Перед изменением кода сделай копию папки программы.
----- конец сообщения -----

4. Когда он спросит разрешения на команды/изменения — нажимать «Разрешить».
5. В конце попросить: «Проверь на ролике про ацтеков: создай проект из How_They_Lived\ролик_ацтеки\prompts.txt».

========================================
ШАГ 4. ПРОВЕРИТЬ МОУШН ОТДЕЛЬНО (можно сразу, не дожидаясь шага 3)
========================================
1. Открыть папку How_They_Lived\моушн
2. Дважды щёлкнуть СДЕЛАТЬ_ТИТРЫ.bat
   - первый раз сам поставит нужный модуль (~1 мин);
   - без субтитров он сделает элементы по отдельности (shot_008_map.mov и т.д.) — это проверка, что всё работает.
   (по умолчанию берёт план ролика про сон; для ацтеков — перетащить мышкой
    ролик_ацтеки\motion_plan.json прямо на СДЕЛАТЬ_ТИТРЫ.bat)
3. Готовые файлы — в моушн\out\<папка ролика>\
4. Когда будет озвучка: положить субтитры .srt из CapCut в папку ролика_ацтеки и запустить ещё раз —
   появится ALL_overlays.mov (одна прозрачная дорожка на весь ролик, класть в CapCut с 0:00).

========================================
ШАГ 5. РОЛИК ПРО АЦТЕКОВ
========================================
Дальше — по файлу ролик_ацтеки\КАК_ДЕЛАТЬ.txt:
  картинки во Flow (инструкции → референсы персонажей → 10 пачек) → озвучка → сборка в программе
  → анимация (Wan на ПК + 10 герой-кадров во Flow) → моушн → описание из description.txt.

========================================
ЕСЛИ ЧТО-ТО НЕ ТАК
========================================
- Ошибка в окне .bat или в программе — сделать скриншот и прислать Claude.
- Google Flow не пропустил кадр — прислать номер кадра.
- Ничего не удаляйте из папки моушн: world_land.js — это карта мира, fonts — шрифты.
